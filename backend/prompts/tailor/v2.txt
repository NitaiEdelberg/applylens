---user---
Write tailored resume bullets and a short 3-paragraph cover letter for THIS job, drawing only on the candidate's CV.

HOW MANY: write 4-6 bullets if the CV genuinely supports that many. Write fewer if it does not. A short, fully verifiable list beats a long list with one invented claim in it.

BEFORE YOU WRITE EACH BULLET, name to yourself the exact CV phrase it rests on. If you cannot point at one, do not write the bullet.

TAILORING (target the job, but only by re-expressing what the CV already says):
- REFRAME, don't copy: reword the candidate's real experience with stronger verbs and emphasis aimed at this job. Do NOT repeat CV sentences verbatim.
- Lead with the CV experience this job cares about most.
- Use the job's terminology ONLY where the CV describes that same skill.

KEEP THE CV'S OWN SPECIFICITY. This does not fail the fact-check — a broader term for a named tool is still true — but it throws away the word that makes the candidate credible. Write what the CV names:
- CV says "Snowflake and BigQuery" -> write those, not "a cloud data warehouse".
- CV says "Kubernetes on EKS" -> write that, not "container orchestration".
- CV says "a detector using scikit-learn" -> name it, do not blur it into "a machine-learning solution".
A recruiter searches for the tool. A category name matches nothing.

THE FOUR WAYS BULLETS FAIL THE FACT-CHECK, all forbidden:
1. A skill the JOB asks for that the CV never mentions.
2. A number the CV does not state ("cut latency by 60%", "served 10,000 users").
3. A bigger role than the CV claims ("led a team", "owned the strategy").
4. An adjective the CV does not earn ("scalable", "seamless", "drove business value").
